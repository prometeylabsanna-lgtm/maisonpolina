# Карта сайту

Документ визначає структуру сайту, перелік сторінок, мовні версії, склад і
функціонал кожного блоку, а також межі самостійного редагування вмісту
Замовником. Після затвердження є підставою для приймання робіт.

---

| Параметр           | Значення                                                                   |
| ------------------ | -------------------------------------------------------------------------- |
| Тип сайту          | Персональний іміджевий лендінг (односторінковий)                           |

## 2. Стиль і подача

Дизайн виконується в мінімалістичному, солідному стилі з акцентом на
персональному бренді Замовника.


| Принцип           | Реалізація                                                                          |
| ----------------- | ----------------------------------------------------------------------------------- |
| Вільний простір   | Значні відступи між блоками, відсутність візуального перевантаження                 |
| Кольорова гама    | Два-три базові кольори; акцентний застосовується точково — кнопки, ключові елементи |
| Типографіка       | Читабельні шрифти, чітка ієрархія заголовків, комфортна довжина рядка               |
| Пріоритет медіа   | Фотографії та відео — домінанта композиції; декоративна графіка мінімальна          |
| Загальне враження | Стриманість і презентабельність замість яскравості та насиченості                   |


### 2.1. Лексика та символіка

Правило поширюється на обидві мовні версії, тексти в макетах і майбутні
матеріали. Ключ — приватність і самодостатність, а не розкіш напоказ.

| | Не вживається | Використовується натомість |
|---|---|---|
| Лексика | luxury, exclusive, princess, queen, VIP, елітний | private, elegance, independent, confidence, business |
| Символіка | Квіти, корони, діаманти, сердечка, блискітки, емодзі | Лінійні іконки без заливки, тонкі золоті лінії, монограма, ромби-буліти |

## 5. Структура головної сторінки

Блоки наведені в порядку розміщення згори вниз.


| Блок                       | Склад                                                                                                                     | Функціонал                                                                                                                                              | Критерій готовності                                                     |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| **Шапка**                  | Логотип або ім'я, меню, перемикач мов, телефон, кнопка дії                                                                | Фіксується при прокручуванні. Перехід по меню — плавний, без перекриття заголовка. Телефон активний для виклику. На мобільних згортається в кнопку меню | Перехід по меню не ховає заголовок блоку під шапкою                     |
| **1. Перший екран**        | Головна теза, підзаголовок, фото або відео, кнопка дії                                                                    | Кнопка відкриває форму заявки або веде до блоку послуг. Для контрасту тексту застосовується затемнення. На мобільних відео замінюється статичним кадром | Текст читабельний на будь-якому фоні, медіа високої якості              |
| **2. Про мене**            | Портрет або відеозвернення, біографія (2–4 абзаци), теза про цінності та підхід                                           | На десктопі — дві колонки, на мобільних — одна. Відео запускається вручну                                                                               | Медіа коректні на мобільних, тексти читаються без збільшення            |
| **3. Галерея**             | 15–20 фотографій                                                                                                          | На десктопі — сітка, на мобільних — стрічка з гортанням. Фото відкривається на весь екран, перехід між знімками стрілками та пальцем                    | Усі фото відкриваються без спотворень, гортання працює на дотик         |
| **4. Послуги та формати**  | 2–5 карток: назва формату, опис, ціна або «за запитом», що входить, кнопка «Замовити». Можливе виділення рекомендованого  | Кнопка «Замовити» передає у форму назву обраного формату. Формат можна приховати без видалення                                                          | У заявці зазначено, який саме формат обрано                             |
| **5. Відгуки**             | Відгуки: текст, ім'я, рід занять, фото за наявності                                                                       | Карусель: гортання пальцем на мобільних, стрілки на десктопі. Довгий відгук згортається                                                                 | Карусель працює обома способами без збоїв                               |
| **6. Питання й відповіді** | 5–10 пар «питання — відповідь», заклик до звернення                                                                       | Відповідь розгортається натисканням, попередня згортається                                                                                              | Одночасно відкрита одна відповідь, висота блоку не змінюється стрибками |

## 10. Узгоджені відхилення від технічного завдання

Наведені зміни погоджені Сторонами та замінюють відповідні пункти ТЗ.
Обсяг робіт зменшено, вартість перегляду не потребує.

| Пункт ТЗ | Передбачено в ТЗ | Узгоджено |
|---|---|---|
| 2.5 | Мовні версії UA та EN | Мовні версії RU та EN |
| 3 | Блок «Переваги / Експертність» | Не реалізується окремим блоком |
| 3 | Блок «Інтерактив / Коментарі» з гілками відповідей | Не реалізується |
| 3 | Соціальний доказ: відгуки, логотипи партнерів, кейси | Реалізуються лише відгуки |
| 4.2 | Повідомлення про успіх **або** сторінка-подяка | Повідомлення про успіх у вікні форми |
| 4.3 | Сповіщення адміністратора про нові коментарі | Не застосовується разом із блоком коментарів |
| 5.3 | Модерація коментарів у панелі керування | Не застосовується разом із блоком коментарів |
| 6 | Тест-кейс №4 «Робота блоку коментарів» | Виключається з чек-листа приймання |

Додано понад ТЗ: окремий розділ «Галерея» на 15–20 фотографій
та окремий розділ «Контакти» з формою заявки.
